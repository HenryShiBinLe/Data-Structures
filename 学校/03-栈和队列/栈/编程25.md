# 编程25 合法的出栈序列

> 7-1　合法的出栈序列　｜　分数 30
> 作者：吴敏华　｜　单位：首都师范大学

n个自然数的入栈顺序为1,2,....n, 输入一个出栈序列,判断其是否是一个合法的出栈序列。n<10。

## 输入格式

输入共二行，第一行中给出正整数n。
第二行给出n个用空格隔开的正整数，表示一个出栈序列

## 输出格式

如果是一个合法的出栈序列输出yes，否则输出no。

## 输入样例 1

```
3
3 2 1
```

## 输出样例 1

```
yes
```

## 输入样例 2

```
3
3 1  2
```

## 输出样例 2

```
no
```
