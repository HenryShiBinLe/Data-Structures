# 编程8 用顺序结构线性表实现整数集合的并集

> 用顺序结构线性表存放整数集合，请用 `SqList` 的基本操作实现整数集合的并集。

## 题目要求

1. 定义用到的宏名（符号常量），如 `OK`、`OVERFLOW` 等
2. 定义类型标识符 `Status`
3. 实现下列函数

## 函数接口定义

```cpp
Status InitList_Sq(SqList &L);

int ListLength_Sq(SqList L);

Status GetElem_Sq(SqList L, int i, ElemType &e);

Status ListInsert_Sq(SqList &L, int i, ElemType e);

int equal(ElemType x, ElemType y);            // 比较 x 与 y 是否相等

int LocateElem_Sq(SqList L, ElemType e, Status (*compare)(ElemType, ElemType));

void union_Sq(SqList La, SqList Lb, SqList &Lc);  // La、Lb 表示集合 A、B，C = A ∪ B
```

## 裁判测试程序样例

```cpp
#include<stdio.h>
#include <stdlib.h>

typedef int ElemType;
#define LIST_INIT_SIZE    30  // 线性表存储空间的初始分配
#define LISTINCREMENT     10  // 线性表存储空间的分配增量

typedef struct {
    ElemType   *elem;     // 存储空间基址
    int        length;    // 当前长度
    int        listsize;  // 当前分配的存储容量(以 sizeof(ElemType) 为单位)
} SqList;

/* 你的程序将嵌在这里 */

int main()
{
    int i, j, len;
    int m, n;              // 分别存放两个集合初始长度
    ElemType e;
    SqList La, Lb, Lc;
    scanf("%d%d", &m, &n);
    InitList_Sq(La); InitList_Sq(Lb);      // 建立两个空集
    for (i = 1; i <= m; i++)               // 建立第一个集合
        { scanf("%d", &e); ListInsert_Sq(La, i, e); }
    for (i = 1; i <= n; i++)               // 建立第二个集合
        { scanf("%d", &e); ListInsert_Sq(Lb, i, e); }
    union_Sq(La, Lb, Lc);                  // 计算集合 La、Lb 的并集 Lc
    len = ListLength_Sq(Lc);
    for (i = 1; i <= len; i++)             // 输出
        { GetElem_Sq(Lc, i, e); printf("%4d", e); }
    return 0;
}
```

## 思路要点

- **并集怎么做**：先把 La 整体拷进 Lc，再逐个扫 Lb，只有 `LocateElem_Sq` 在 Lc 中找不到（返回 `FALSE`）时才追加，天然保证结果无重复。
- **`LocateElem_Sq` 的返回值**：找到返回**位序**（从 1 开始，所以是 `return ++i`），找不到返回 `FALSE`（0）。位序从 1 开始正是为了跟 0 区分开。
- **`compare` 是函数指针**：把"怎么算相等"交给调用方传进来（这里传 `equal`），换成结构体元素时只要换比较函数，查找逻辑不用动。
- **`ListInsert_Sq` 的扩容**：`length == listsize` 时用 `realloc` 扩 `LISTINCREMENT`，且要**先用临时指针接住**再赋值给 `L.elem`，否则 realloc 失败会把原指针也丢掉，造成内存泄漏。
- **元素后移方向**：从表尾往插入位置倒着搬（`for (end = L.length - 1; end >= start; end--)`），正着搬会把后面的数据覆盖掉。
- 位置参数 `i` 是**位序**，数组下标要用 `i - 1`；插入的合法范围是 `[1, length + 1]`，比查找多一个"接在末尾"的位置。
