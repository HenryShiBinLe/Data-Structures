# 编程18 多项式求导2

> 7-2　多项式求导2　｜　分数 30
> 作者：吴敏华　｜　单位：首都师范大学

设计程序求一元多项式的导数。

## 输入格式

输入一共 2 行，第一行是多项式的项数，第二行给出每一项的系数和指数。系数和指数都是绝对值不超过 1000 的整数。系数不可能为 0。

## 输出格式

输出多项式求导后每一项的系数和指数，中间用空格隔开，但结尾不能有多余空格。指数递增有序。

## 输入样例 1

```
4
3 4 -5 2 6 1 -2 0
```

## 输出样例 1

```
6 0 -10 1 12 3
```

## 输入样例 2

```
1
-2 0
```

## 输出样例 2

```
0 0
```
